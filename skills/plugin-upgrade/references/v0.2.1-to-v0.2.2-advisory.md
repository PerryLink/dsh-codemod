# Advisory: `0.2.1-rc.5` → `0.2.2-alpha.3`

> **Not a corridor.** This card does not add a scanned seam set and does not change the
> `legD` claim. It records the 0.2.2-alpha.3 deltas that a `0.2.x` plugin can hit, so a
> clean `legD` scan is not mistaken for "0.2.2 compatible".

Evidence is pinned to `deepseek-harness` tag `dsh-v0.2.2-alpha.3`
(commit `05b1cae8`, 2026-11-03) and to the published `@deepseek-ai/*@0.2.2-alpha.3`
packages.

## A1 — Node minimum moved to 24.9

- `package.json` `engines.node` is `>=24.9.0` at `0.2.2-alpha.3`
  (`^22.19.0 || >=24.0.0` at `0.2.1-rc.5`).
- Source: official upgrade guide `v0.2.1-rc.2/node-24`; tag root `package.json`.
- Check: `node -v` in the plugin's CI and in the profile host; a Node 22 runner now
  fails before the plugin loads.

## A2 — `ctx.menus` was removed

- Renamed to `ctx.contextMenus` with `ContextMenuTargetMap`; no compatibility alias.
- Source: `docs/upgrade-guide/v0.2.1-rc.2/context-menu-services/guide.zh.md`.
- Check: `rg '\bctx\.menus\b|MenuTargetMap'` — any hit fails activation at runtime, not
  at build time.

## A3 — `DSH_TOOLS_MODE` is ignored

- Tool execution moved to explicit executor plugins
  (`dsh-tool-executor-native` / `dsh-tool-executor-ptc`); `dsh-tools` rejects the removed
  `mode` and `maxParallelSubCalls` fields.
- Source: `docs/upgrade-guide/v0.2.1-rc.2/tool-executor-plugins/guide.zh.md`;
  `packages/bundle/sdk-app/README.md` ("DSH_TOOLS_MODE is ignored").
- Check: profile patch, CI env, and docs snippets for `DSH_TOOLS_MODE`; move PTC config to
  the executor row.

## A4 — Typert codec shape: `schema` → `create()`

- `TypertCodec` is now `TypertRemoteValue & { mode: 'strict', typeSymbol, ... }`, and
  `TypertRemoteValue` requires `create(): TypertSchema`.
- Old `{ mode, typeSymbol, schema }` fails typecheck against `0.2.2-alpha.3`.
- Source: `packages/typert/protocol/src/types.ts` (tag), generator output
  `packages/typert/generator/src/emitter.ts` (`create: <schema>`).
- Fix: `codec: { mode: 'strict', typeSymbol, create: () => schema }`.
- Check: generated `/remote` artifacts and hand-written `contract.ts` files.

## A5 — `dsh-client-runtime` has no 0.2.x release

- Highest published version is `0.1.1-rc.2`; official client packages no longer depend on
  it. Keeping it in `peerDependencies` makes `autoInstallPeers` resolve `0.0.1-rc.1`,
  which depends on the unpublished `@deepseek-ai/dsh-compact` and fails install.
- Replacement: `import type { Context } from '@deepseek-ai/cordis'`, plus declaration
  merging from `@deepseek-ai/dsh-api-remotes/client` (`ctx.remote`) and
  `@deepseek-ai/dsh-client-ui-renderer/client` (`ctx.slots`).
- Check: `rg 'dsh-client-runtime' package.json`.

## A6 — `dsh-agent-tool-presentation` is deprecated

- Still shipped, selector still accepted, but `tool-executor-*` is the supported surface.
- Check: only report; do not auto-rewrite.

## Verification recipe

```sh
node -v                                   # >= 24.9
rg 'ctx\.menus|DSH_TOOLS_MODE|dsh-client-runtime' .
rg "mode: 'strict'" -n . | rg 'schema'
```
